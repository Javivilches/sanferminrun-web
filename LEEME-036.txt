SAN FERMÍN RUN 0.3.6 · WEB PARA SAFARI Y OTROS NAVEGADORES

1. Descomprime el ZIP. Sube el contenido de web (no el ZIP) a la
   carpeta que publica GitHub Pages en tu repositorio de la web.
   No se publica en el repositorio del servidor. Los archivos .bin
   ya están divididos en partes de menos de 25 MB. Conserva los nombres.
2. En el iPhone, abre el enlace HTTPS de Pages en Safari. Para quitar
   la barra de Safari, pulsa Compartir > Añadir a pantalla de inicio,
   activa Abrir como app web si aparece y abre desde el nuevo icono.
3. Si el navegador admite compartir archivos, Compartir abre el menú del
   dispositivo. Si no está disponible, usa Guardar archivo. El vídeo
   portable se exporta como MP4 vertical sin sonido.

El multijugador conserva el servidor y protocolo de la 0.3.5. Si
tenías una URL distinta configurada manualmente, introdúcela también
en este cliente. Para una prueba privada usa la misma sala en ambos.
